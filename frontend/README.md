# Tripleten web_project_around_auth

## Descripción

Este proyecto es un ejemplo de una red social donde se pueden comartir imagenes de diversas partes del mundo.

## Funcionalidades

Dentro de las funcionalidades se encuentran las siguientes: registro de usuarios, inicio de sesión de usuarios registrados, conservar el inicio de sesión dentro de la memoria del navegador, rutas protegidas cuando no hay un inicio de sesión, redireccionamiento automático a login cuando no se detecta un inicio de sesión, editar información de un usuario, agregar y eliminar tarjetas, poder dar me gusta o eliminar me gusta de una tarjeta, etc.

## Cómo ejecutar el proyecto

Para ejecutar el proyecto utilizamos el comando "npm run dev" el cual lo ejecutará en en el puerto 3000 de localhost además de abirlo automáticamente
